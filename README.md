AI/ML Internship Assignment 1
# E-commerce Sales Data Analysis 📊

## Overview
This project is a part of my AI/ML Internship Assignment 1, where I worked on analyzing an E-commerce Sales Dataset using Python.

The main objective of this project was to understand the fundamentals of data analysis and explore how raw business data can be converted into meaningful insights.

---

## Objectives
- Understand and analyze e-commerce sales data
- Identify sales and profit trends
- Explore product/category performance
- Compare regional sales performance
- Visualize data using graphs and charts
- Build a strong foundation in Data Analysis for AI/ML

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset Features
The dataset contains information related to:
- Order Date
- Product Name
- Category
- Region
- Quantity
- Sales
- Profit

---

## Analysis Performed
✔️ Data Cleaning  
✔️ Data Exploration  
✔️ Sales Trend Analysis  
✔️ Profit Analysis  
✔️ Category-wise Performance  
✔️ Regional Comparison  
✔️ Data Visualization

Through this project, I learned:
